# HTML Learning Repository

This repository contains my **HTML learning journey** as part of my Full Stack Web Development course.

I created this repository to practice HTML from the fundamentals and build a strong foundation for frontend web development.

## 📌 About This Repository

This repository includes my HTML practice codes, examples, exercises, and small web pages that I created while learning.

The main goal is to understand how HTML is used to create the **structure and content of websites** before moving deeper into CSS, JavaScript, React, and full-stack development.

You can clone this repository and open the HTML files directly in a web browser.

```bash

```

Then open any `.html` file in your browser.

You can also use **Visual Studio Code** with the **Live Server** extension to run the pages locally.
